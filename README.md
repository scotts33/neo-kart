# Neon Circuit 2026

Browser arcade kart racer (Mario Kart–style mechanics, original theme).

**https://rawcdn.githack.com/scotts33/neo-kart/main/index.html**

## Controls

W/↑ accel · S/↓ brake · A D steer · Shift drift · Space item · C camera · P pause
